Follow the root [README.md](../README.md): Docker for Postgres/Redis, `npx prisma migrate deploy`, `npm run dev`, and `npm run dev:collab`. Open two browsers on the same page.

If a live deploy is unavailable, submit a screen recording of the two-browser session plus this repository.
