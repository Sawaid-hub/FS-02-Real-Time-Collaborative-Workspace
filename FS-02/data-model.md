# Data Model Specification

Prisma models live in `prisma/schema.prisma`. PostgreSQL 16 is the relational source of truth.

## Entities & Enums

### Core Workspace & Identity
- **User:** `id`, `email` (unique), `name`, `passwordHash`, `createdAt`.
- **Workspace:** `id`, `name`, `ownerId` (relation to User), `createdAt`.
- **Membership:** `userId`, `workspaceId`, `role` (`VIEW` | `COMMENT` | `EDIT`), unique `(userId, workspaceId)`.

### Documents & Real-Time CRDT Collaboration
- **Page:** `id`, `workspaceId`, `title`, `yDoc` (bytes, `Y.encodeStateAsUpdate` binary), `updatedAt`.
- **Comment:** `id`, `pageId`, `authorId`, `body`, `anchorJson` (optional TipTap text range anchor), `createdAt`.
- **Snapshot:** `id`, `pageId`, `authorId`, `label`, `yDoc` (bytes, version snapshot), `previewHtml` (rendered HTML preview), `createdAt`.

### Projects & Task Tracking (Notion/AFFiNE Scope)
- **Project:**
  - `id`: CUID identifier
  - `workspaceId`: Workspace reference
  - `name`: String (1-120 chars)
  - `description`: String (optional)
  - `status`: `ProjectStatus` enum (`PLANNING` | `ACTIVE` | `ON_HOLD` | `COMPLETED` | `CANCELLED`)
  - `color`: Hex color accent (e.g. `#1e96eb`)
  - `startDate`: DateTime (optional)
  - `targetDate`: DateTime (optional)
  - `createdAt`, `updatedAt`: DateTime
  - Relations: `workspace`, `tasks`, `files`

- **Task:**
  - `id`: CUID identifier
  - `workspaceId`: Workspace reference
  - `projectId`: Project reference (optional)
  - `title`: String (1-200 chars)
  - `description`: String (optional)
  - `status`: `TaskStatus` enum (`TODO` | `IN_PROGRESS` | `IN_REVIEW` | `DONE`)
  - `priority`: `TaskPriority` enum (`LOW` | `MEDIUM` | `HIGH` | `URGENT`)
  - `assigneeId`: User reference (optional)
  - `dueDate`: DateTime (optional)
  - `order`: Integer sequence order for drag-and-drop / column ordering
  - `createdAt`, `updatedAt`: DateTime

- **ProjectFile:**
  - `id`: CUID identifier
  - `projectId`: Project reference
  - `name`: String (filename)
  - `size`: Integer (bytes)
  - `mimeType`: String
  - `url`: Relative download URL (`/uploads/...`)
  - `uploaderId`: User reference
  - `createdAt`: DateTime

## Foreign Keys & Indexes

- `Membership`: `@@id([userId, workspaceId])`, `@@index([userId])`, `@@index([workspaceId])`
- `Page`: `@@index([workspaceId])`
- `Comment`: `@@index([pageId])`, `@@index([authorId])`
- `Snapshot`: `@@index([pageId])`
- `Project`: `@@index([workspaceId])`, `@@index([status])`
- `Task`: `@@index([workspaceId])`, `@@index([projectId])`, `@@index([status])`, `@@index([assigneeId])`
- `ProjectFile`: `@@index([projectId])`

## Real-Time Room Mapping

- Collaborative Page Room: `page:{pageId}` generated by `roomNameForPage` in `lib/collab/rooms.ts`.
